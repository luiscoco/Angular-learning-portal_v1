About this learning portal

This project is intentionally lightweight but structured. Use it as a starting point for your own Angular-based learning hub.

Architecture ideas

  • Separate core (services, layout) from features.
  • Add lazy-loaded feature modules as the project grows.
  • Introduce a shared module for reusable components.

Next steps for you

  • Persist progress in localStorage or Supabase.
  • Connect to a real backend or CMS to store lessons.
  • Add authentication and role-based access for students / admins.
